## Главное

**Комплексное число** — выражение $z = a + bi$, где $a, b \in \mathbb{R}$, а $i$ — мнимая единица, $i^2 = -1$. Число $a = \operatorname{Re} z$ — действительная часть, $b = \operatorname{Im} z$ — мнимая часть. Числа $z = a+bi$ и $\bar z = a - bi$ называются **сопряжёнными**; $z\bar z = a^2 + b^2$ — всегда действительное неотрицательное число.

Числу $z = a+bi$ соответствует точка $(a; b)$ (или вектор) на **комплексной плоскости**: ось абсцисс — действительная, ось ординат — мнимая.

- **Модуль:** $\lvert z\rvert = r = \sqrt{a^2 + b^2}$ — расстояние от начала координат.
- **Аргумент:** $\varphi = \arg z$ — угол между положительным направлением оси $Ox$ и вектором $z$. Он определён с точностью до $2\pi k$. **Главное значение** $\arg z \in (-\pi; \pi]$ (в некоторых курсах $[0; 2\pi)$, смотрите, как принято на лекциях).
- Для $z = a + bi \ne 0$: $\cos\varphi = a/r$, $\sin\varphi = b/r$. Не путайте с $\operatorname{arctg}(b/a)$: учитывайте четверть, в которой лежит точка.

## Три формы записи

- **Алгебраическая:** $z = a + bi$.
- **Тригонометрическая:** $z = r(\cos\varphi + i\sin\varphi)$.
- **Показательная:** $z = r e^{i\varphi}$, где $e^{i\varphi} = \cos\varphi + i\sin\varphi$ (формула Эйлера).

Перевод: $a = r\cos\varphi$, $b = r\sin\varphi$.

## Операции в алгебраической форме

Для $z_1 = a_1 + b_1 i$, $z_2 = a_2 + b_2 i$:

$$z_1 \pm z_2 = (a_1 \pm a_2) + (b_1 \pm b_2)i,\qquad z_1 z_2 = (a_1 a_2 - b_1 b_2) + (a_1 b_2 + a_2 b_1)i.$$

**Деление:** домножить числитель и знаменатель на число, сопряжённое знаменателю:

$$\frac{z_1}{z_2} = \frac{z_1\bar z_2}{z_2\bar z_2} = \frac{(a_1 a_2 + b_1 b_2) + (a_2 b_1 - a_1 b_2)i}{a_2^2 + b_2^2}.$$

Степени $i$ повторяются с периодом 4: $i^1 = i$, $i^2 = -1$, $i^3 = -i$, $i^4 = 1$.

Свойства: $\overline{z_1 z_2} = \bar z_1 \bar z_2$, $\lvert z_1 z_2\rvert = \lvert z_1\rvert\lvert z_2\rvert$, $\lvert z\rvert^2 = z\bar z$.

## Операции в тригонометрической форме

Пусть $z_1 = r_1(\cos\varphi_1 + i\sin\varphi_1)$, $z_2 = r_2(\cos\varphi_2 + i\sin\varphi_2)$.

$$z_1 z_2 = r_1 r_2\bigl(\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)\bigr),\qquad \frac{z_1}{z_2} = \frac{r_1}{r_2}\bigl(\cos(\varphi_1 - \varphi_2) + i\sin(\varphi_1 - \varphi_2)\bigr).$$

То есть при умножении **модули перемножаются, аргументы складываются**; при делении модули делятся, аргументы вычитаются.

**Формула Муавра** (возведение в степень $n \in \mathbb{N}$):

$$z^n = r^n(\cos n\varphi + i\sin n\varphi).$$

**Извлечение корня $n$-й степени.** Число $z = r(\cos\varphi + i\sin\varphi) \ne 0$ имеет ровно $n$ различных корней:

$$w_k = \sqrt[n]{r}\left(\cos\frac{\varphi + 2\pi k}{n} + i\sin\frac{\varphi + 2\pi k}{n}\right),\quad k = 0, 1, \dots, n-1.$$

Они лежат в вершинах правильного $n$-угольника с центром в нуле.

**Квадратное уравнение** $az^2 + bz + c = 0$ с $D = b^2 - 4ac < 0$ имеет два сопряжённых комплексных корня $z_{1,2} = \dfrac{-b \pm i\sqrt{\lvert D\rvert}}{2a}$.

## Разобранные примеры

**1. Действия.** $z_1 = 2 + i$, $z_2 = 3 - 2i$.

$z_1 + z_2 = 5 - i$; $z_1 - z_2 = -1 + 3i$; $z_1 z_2 = 6 - 4i + 3i - 2i^2 = 8 - i$;

$$\frac{z_1}{z_2} = \frac{(2+i)(3+2i)}{(3-2i)(3+2i)} = \frac{6 + 4i + 3i - 2}{13} = \frac{4 + 7i}{13}.$$

**2. Модуль, аргумент, формы.** $z = -1 + i$. Точка во II четверти. $r = \sqrt{1 + 1} = \sqrt 2$, $\cos\varphi = -\tfrac{1}{\sqrt 2}$, $\sin\varphi = \tfrac{1}{\sqrt 2}$, значит $\varphi = \tfrac{3\pi}{4}$.

$$z = \sqrt 2\left(\cos\tfrac{3\pi}{4} + i\sin\tfrac{3\pi}{4}\right) = \sqrt 2\, e^{3\pi i/4}.$$

**3. Муавр.** $(1+i)^{12}$. Для $1 + i$: $r = \sqrt 2$, $\varphi = \tfrac{\pi}{4}$. Тогда

$$(1+i)^{12} = (\sqrt 2)^{12}\left(\cos 3\pi + i\sin 3\pi\right) = 64\cdot(-1) = -64.$$

Ещё: $(-1 + i\sqrt 3)^6$: $r = 2$, $\varphi = \tfrac{2\pi}{3}$, получаем $2^6(\cos 4\pi + i\sin 4\pi) = 64$.

**4. Корень.** $\sqrt{3 + 4i}$. Здесь удобнее алгебраически: $(x + yi)^2 = 3 + 4i$, откуда $x^2 - y^2 = 3$, $2xy = 4$. Подходит $x = 2$, $y = 1$. Ответ: $\pm(2 + i)$. Проверка: $(2+i)^2 = 4 + 4i - 1 = 3 + 4i$.

**5. Кубический корень.** $z^3 = 1$: $r = 1$, $\varphi = 0$, $w_k = \cos\tfrac{2\pi k}{3} + i\sin\tfrac{2\pi k}{3}$:

$$w_0 = 1,\quad w_1 = -\tfrac12 + \tfrac{\sqrt 3}{2}i,\quad w_2 = -\tfrac12 - \tfrac{\sqrt 3}{2}i.$$

**6. Квадратное уравнение.** $z^2 - 4z + 5 = 0$: $D = 16 - 20 = -4$, $z = \dfrac{4 \pm 2i}{2} = 2 \pm i$.

**7. Прикладная (из ФОС).** Сигнал $z = 3 + 4i$: амплитуда $\lvert z\rvert = 5$, фаза $\arg z = \operatorname{arctg}\tfrac43 \approx 53{,}13^\circ$. Умножение на $w = 1 + i$ ($\lvert w\rvert = \sqrt 2$, $\arg w = 45^\circ$): амплитуда растёт в $\sqrt 2$ раз, фаза поворачивается на $45^\circ$. Результат $zw = (3 + 4i)(1 + i) = -1 + 7i$, $\lvert zw\rvert = \sqrt{50} = 5\sqrt 2$.

## Типичные ошибки

- Аргумент находят только как $\operatorname{arctg}(b/a)$ и не учитывают четверть (для $-1 + i$ это даёт $-\pi/4$ вместо $3\pi/4$).
- При делении забывают домножить и на числитель, и на знаменатель.
- В формуле Муавра возводят в степень и модуль, и угол умножают на $n$ (а не наоборот: модуль в степень $n$, угол умножается на $n$).
- Забывают $2\pi k$ при извлечении корня: корней ровно $n$.
