## Кривые второго порядка

**Кривая второго порядка** на плоскости задаётся уравнением $Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$ (хотя бы один из $A, B, C$ не нуль). Это эллипс (в частности окружность), гипербола, парабола или вырожденные случаи (пара прямых, точка, пустое множество). Классификация по инвариантам: знак $B^2 - 4AC$ — отрицательный для эллиптического типа, положительный для гиперболического, нулевой для параболического.

### Эллипс

Геометрическое место точек, для которых сумма расстояний до двух фокусов $F_1, F_2$ постоянна ($= 2a$, больше расстояния между фокусами $2c$).

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1,\quad a \ge b > 0,\qquad c^2 = a^2 - b^2.$$

$a$, $b$ — полуоси, фокусы $F_{1,2}(\pm c; 0)$, **эксцентриситет** $e = c/a \in [0, 1)$ (у окружности $e = 0$), директрисы $x = \pm a/e$. Оптическое свойство: луч из одного фокуса после отражения от эллипса проходит через другой.

### Гипербола

Геометрическое место точек с постоянной **разностью** расстояний до фокусов ($= 2a < 2c$).

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1,\qquad c^2 = a^2 + b^2.$$

$a$ — действительная, $b$ — мнимая полуось, фокусы $(\pm c; 0)$, $e = c/a > 1$, **асимптоты** $y = \pm\dfrac bax$, директрисы $x = \pm a/e$. **Сопряжённая** гипербола: $-\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ (ветви вдоль оси $Oy$, те же асимптоты).

### Парабола

Геометрическое место точек, равноудалённых от фокуса $F$ и прямой — директрисы.

$$y^2 = 2px,\qquad F\left(\tfrac p2; 0\right),\qquad \text{директриса } x = -\tfrac p2,\quad e = 1.$$

Вершина в начале координат, ось симметрии $Ox$; ветви вправо при $p > 0$. Вариант $x^2 = 2py$: ось $Oy$, $F(0; \tfrac p2)$, директриса $y = -\tfrac p2$.

### Приведение к каноническому виду

1. Если есть член $Bxy$, поворачивают оси на угол $\alpha$, где $\operatorname{ctg}2\alpha = \dfrac{A - C}{B}$, чтобы его убрать.
2. Выделяют полные квадраты по $x$ и $y$ (параллельный перенос начала в центр).
3. Приводят к виду $\dfrac{(x - x_0)^2}{a^2} \pm \dfrac{(y - y_0)^2}{b^2} = 1$ или $(y - y_0)^2 = 2p(x - x_0)$.

**Касательная** в точке $(x_0, y_0)$ к эллипсу: $\dfrac{xx_0}{a^2} + \dfrac{yy_0}{b^2} = 1$; к гиперболе: $\dfrac{xx_0}{a^2} - \dfrac{yy_0}{b^2} = 1$; к параболе $y^2 = 2px$: $yy_0 = p(x + x_0)$. Прямая и кривая имеют 0, 1 (касание) или 2 общие точки.

## Поверхности второго порядка

Общее уравнение $Ax^2 + By^2 + Cz^2 + 2Dxy + 2Exz + 2Fyz + Gx + Hy + Iz + J = 0$. Канонические виды (центр в начале координат):

| Поверхность | Уравнение |
|---|---|
| Эллипсоид | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} + \dfrac{z^2}{c^2} = 1$ |
| Однополостный гиперболоид | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = 1$ |
| Двуполостный гиперболоид | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = -1$ |
| Эллиптический параболоид | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 2z$ |
| Гиперболический параболоид | $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 2z$ |
| Конус | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = 0$ |
| Эллиптический цилиндр | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ |
| Гиперболический цилиндр | $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ |
| Параболический цилиндр | $y^2 = 2px$ |

**Метод сечений:** чтобы понять форму, пересекают поверхность плоскостями $z = h$ (горизонтальные) и координатными. Эллипсоид даёт эллипсы (или точку, пустое множество на краях); однополостный гиперболоид — эллипсы в горизонтальных сечениях и гиперболы в вертикальных; двуполостный — два «купола» (эллипсы при $\lvert z\rvert > c$); эллиптический параболоид — эллипсы сверху и параболы сбоку; гиперболический параболоид («седло») — гиперболы и параболы. **Цилиндрическая поверхность:** в уравнении нет одной из переменных (поэтому по этой оси образующие параллельны).

**Поверхность вращения:** чтобы получить уравнение поверхности, образованной вращением кривой $f(y, z) = 0$ вокруг оси $Oz$, заменяют $y$ на $\pm\sqrt{x^2 + y^2}$: $f\left(\pm\sqrt{x^2 + y^2},\ z\right) = 0$.

## Разобранные примеры

**1. Приведение кривой.** $9x^2 + 4y^2 - 54x + 16y + 61 = 0$.

$9(x^2 - 6x) + 4(y^2 + 4y) + 61 = 0 \Rightarrow 9(x - 3)^2 - 81 + 4(y + 2)^2 - 16 + 61 = 0 \Rightarrow 9(x - 3)^2 + 4(y + 2)^2 = 36.$

Делим на 36: $\dfrac{(x - 3)^2}{4} + \dfrac{(y + 2)^2}{9} = 1$. Это **эллипс** с центром $(3; -2)$, полуосями $2$ (по $x$) и $3$ (по $y$); $c = \sqrt{9 - 4} = \sqrt5$, фокусы $(3;\ -2 \pm \sqrt5)$ на вертикальной оси эллипса, $e = \tfrac{\sqrt5}{3}$.

**2. Парабола.** Вершина в нуле, ось $Ox$, точка $M(4, -8)$: $y^2 = 2px \Rightarrow 64 = 8p$, $p = 8$, уравнение $y^2 = 16x$, фокус $(4; 0)$, директриса $x = -4$.

**3. Гипербола.** $\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1$: $a = 3$, $b = 4$, $c = 5$, фокусы $(\pm5; 0)$, асимптоты $y = \pm\tfrac43x$, $e = \tfrac53$.

**4. Эллипс и фокусы.** $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$: $a = 5$, $b = 3$, $c = 4$, $F(\pm4; 0)$, $e = 0{,}8$. Уравнение $4x^2 + 9y^2 = 36$ после деления на 36 даёт $\dfrac{x^2}{9} + \dfrac{y^2}{4} = 1$ — тоже эллипс (ответ теста).

**5. Поверхность.** $4x^2 + 9y^2 + 36z^2 - 8x + 36y - 72z + 4 = 0$.

$4(x - 1)^2 - 4 + 9(y + 2)^2 - 36 + 36(z - 1)^2 - 36 + 4 = 0 \Rightarrow 4(x - 1)^2 + 9(y + 2)^2 + 36(z - 1)^2 = 72.$

Делим на 72: $\dfrac{(x - 1)^2}{18} + \dfrac{(y + 2)^2}{8} + \dfrac{(z - 1)^2}{2} = 1$. Это **эллипсоид** с центром $(1; -2; 1)$ и полуосями $3\sqrt2$, $2\sqrt2$, $\sqrt2$. Сечения координатными плоскостями (и параллельными им) — эллипсы.

**6. Сечения слоёв (прикладная из ФОС).** Для эллипсоида $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} + \dfrac{z^2}{c^2} = 1$ слой $z = h$ даёт эллипс $\dfrac{x^2}{a^2(1 - h^2/c^2)} + \dfrac{y^2}{b^2(1 - h^2/c^2)} = 1$ с полуосями $a\sqrt{1 - h^2/c^2}$ и $b\sqrt{1 - h^2/c^2}$: чем выше слой, тем меньше эллипс, поэтому сопло проходит меньший путь, и верхние слои требуют меньше материала.

**7. Пересечение кривых.** Парабола $y^2 = 8x$ и эллипс: подставляют $x = y^2/8$ в уравнение эллипса и получают уравнение на $y$; найденные точки обязательно проверяют подстановкой в оба уравнения.

## Типичные ошибки

- Забывают перенести свободные члены, делят не на то число (в канонической форме справа должна быть единица).
- Путают, какая полуось больше (по ней направлена «длинная» ось и лежат фокусы).
- Для гиперболы используют $c^2 = a^2 - b^2$ (это для эллипса).
- Для параболы $y^2 = 2px$ называют параметром $p$ то, что в записи $y^2 = ax$ равно $a$ (тогда $p = a/2$).
