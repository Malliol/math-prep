## Главное

**Линейное (векторное) пространство** над полем $\mathbb{R}$ — множество $V$ с операциями сложения векторов и умножения на число, удовлетворяющими 8 аксиомам: коммутативность и ассоциативность сложения, существование нулевого вектора и противоположного вектора для каждого, $1\cdot x = x$, $\lambda(\mu x) = (\lambda\mu)x$, $(\lambda+\mu)x = \lambda x + \mu x$, $\lambda(x+y) = \lambda x + \lambda y$.

Примеры: $\mathbb{R}^n$ (столбцы из $n$ чисел); матрицы фиксированного размера; многочлены степени $\le n$; функции, непрерывные на отрезке. **Не** линейное пространство: многочлены степени **ровно** $n$ (сумма может иметь меньшую степень; нет нулевого элемента).

**Подпространство** — подмножество, замкнутое относительно сложения и умножения на число. **Сумма** подпространств $L_1 + L_2$ — все $x_1 + x_2$; **пересечение** $L_1\cap L_2$ тоже подпространство. Формула: $\dim(L_1 + L_2) = \dim L_1 + \dim L_2 - \dim(L_1\cap L_2)$.

## Линейная зависимость, базис, размерность

Система $a_1, \dots, a_k$ **линейно зависима**, если существуют числа $\lambda_1, \dots, \lambda_k$, не все равные нулю, что $\lambda_1 a_1 + \dots + \lambda_k a_k = 0$; иначе — **линейно независима**. Эквивалентно: линейно зависима $\iff$ один из векторов выражается через остальные.

**Проверка в $\mathbb{R}^n$:** составить матрицу из векторов (по строкам или столбцам). Независимы $\iff$ ранг равен числу векторов. Для $n$ векторов в $\mathbb{R}^n$: независимы $\iff \det \ne 0$.

**Базис** — линейно независимая система, через которую выражается любой вектор пространства. **Размерность** $\dim V$ — число векторов в базисе (одно и то же для любых базисов). В $\mathbb{R}^n$ стандартный базис $e_1 = (1,0,\dots)$, $\dots$, $e_n$. **Координаты** вектора $x$ в базисе $e_1, \dots, e_n$ — единственные числа $x_i$, что $x = x_1 e_1 + \dots + x_n e_n$.

**Ранг системы векторов** — максимальное число линейно независимых векторов (равен рангу матрицы из них). **Теорема о базисе:** любые $n$ независимых векторов $n$-мерного пространства образуют базис; любую независимую систему можно дополнить до базиса.

## Смена базиса

Пусть новый базис $f_j = \sum_i t_{ij} e_i$. **Матрица перехода** $T = (t_{ij})$ имеет в столбцах координаты новых векторов в старом базисе. Для координат $x_e$ вектора в старом и $x_f$ в новом базисе

$$x_e = T x_f,\qquad x_f = T^{-1}x_e.$$

## Евклидово пространство

**Евклидово пространство** — линейное пространство со скалярным произведением $(x, y)$ (симметричное, линейное, $(x,x) > 0$ при $x \ne 0$). Норма $\lVert x\rVert = \sqrt{(x,x)}$, угол $\cos\varphi = \dfrac{(x,y)}{\lVert x\rVert\lVert y\rVert}$. Векторы **ортогональны**, если $(x, y) = 0$.

**Неравенство Коши — Буняковского:** $\lvert(x, y)\rvert \le \lVert x\rVert\lVert y\rVert$ (равенство $\iff$ векторы коллинеарны). Из него следует корректность определения угла и неравенство треугольника $\lVert x + y\rVert \le \lVert x\rVert + \lVert y\rVert$.

**Ортогональный базис** — базис из попарно ортогональных векторов; **ортонормированный** — ещё и с нормой 1. **Процесс ортогонализации Грама — Шмидта:** из независимой системы $a_1, \dots, a_k$

$$b_1 = a_1,\qquad b_2 = a_2 - \frac{(a_2, b_1)}{(b_1, b_1)}b_1,\qquad b_3 = a_3 - \frac{(a_3, b_1)}{(b_1, b_1)}b_1 - \frac{(a_3, b_2)}{(b_2, b_2)}b_2,\ \dots$$

Затем нормируют: $e_i = b_i/\lVert b_i\rVert$. **Матрица Грама** $G = ((e_i, e_j))$; для ортонормированного базиса $G = E$.

## Разобранные примеры

**1. Не пространство.** Множество многочленов степени **ровно** $n$ не является линейным пространством (сумма $x^n + (-x^n + 1)$ имеет степень $0$, нулевого многочлена в множестве нет). Многочлены степени $\le n$ с комплексными коэффициентами образуют линейное пространство (размерность $n+1$).

**2. Линейная зависимость.** $a_1 = (5, 4, 3)$, $a_2 = (3, 3, 2)$, $a_3 = (8, 1, 3)$. Определитель из этих векторов равен $0$, поэтому система зависима. Явно: $a_3 = 7a_1 - 9a_2$ (проверка: $35 - 27 = 8$; $28 - 27 = 1$; $21 - 18 = 3$).

Для $a_1 = (2, -3, 1)$, $a_2 = (3, -1, 5)$, $a_3 = (1, -4, 3)$: $\det = 35 \ne 0$, система независима, это базис $\mathbb{R}^3$.

**3. Базис $\mathbb{R}^4$.** Векторы $e_1 = (1,2,-1,2)$, $e_2 = (2,3,0,-1)$, $e_3 = (1,2,1,4)$, $e_4 = (1,3,-1,0)$, $e_5 = (-2,-4,2,-4)$. Заметим $e_5 = -2e_1$. Определитель из $e_1, e_2, e_3, e_4$ равен $18 \ne 0$, поэтому они образуют базис. Пять векторов в $\mathbb{R}^4$ всегда зависимы, ранг системы равен 4. Любая четвёрка, содержащая и $e_1$, и $e_5$, зависима (определитель 0).

**4. Скалярное произведение и угол.** $x = (2,1,3,2)$, $y = (1,2,-2,1)$: $(x, y) = 2 + 2 - 6 + 2 = 0$, векторы ортогональны, угол $90^\circ$. Для $x = (2,1,-1,2)$, $y = (3,-1,-2,1)$: $(x, y) = 6 - 1 + 2 + 2 = 9$.

**5. Матрица перехода.** Старый базис $e_1 = (1, 0)$, $e_2 = (1, 1)$; новый $f_1 = (1, 1)$, $f_2 = (0, 1)$. $f_1 = 0\cdot e_1 + 1\cdot e_2$, $f_2 = -e_1 + e_2$ (проверка: $-(1,0) + (1,1) = (0,1)$). Матрица перехода $T = \begin{pmatrix} 0 & -1 \\ 1 & 1 \end{pmatrix}$ (в столбцах координаты $f_1$, $f_2$ в базисе $e$).

**6. Ортогонализация.** $a_1 = (2,-2,-2,2)$, $a_2 = (3,-1,-1,3)$, $a_3 = (2,-2,0,4)$.

$b_1 = a_1 = (2,-2,-2,2)$, $(b_1, b_1) = 16$. $(a_2, b_1) = 6 + 2 + 2 + 6 = 16$, значит $b_2 = a_2 - 1\cdot b_1 = (1, 1, 1, 1)$. Для $a_3$: $(a_3, b_1) = 4 + 4 + 0 + 8 = 16$, $(a_3, b_2) = 2 - 2 + 0 + 4 = 4$, $(b_2, b_2) = 4$, поэтому $b_3 = a_3 - b_1 - 1\cdot b_2 = (2-2-1,\ -2+2-1,\ 0+2-1,\ 4-2-1) = (-1, -1, 1, 1)$.

Ортогональный базис: $b_1, b_2, b_3$ (проверка: $(b_1, b_3) = -2 + 2 - 2 + 2 = 0$, $(b_2, b_3) = 0$). Ортонормированный: $\tfrac14 b_1 = (\tfrac12, -\tfrac12, -\tfrac12, \tfrac12)$, $\tfrac12 b_2 = (\tfrac12,\tfrac12,\tfrac12,\tfrac12)$, $\tfrac12 b_3 = (-\tfrac12,-\tfrac12,\tfrac12,\tfrac12)$. Дополнить до базиса $E^4$ можно вектором, ортогональным всем трём: из условий $(v, b_i) = 0$ получается $v \sim (1, -1, 1, -1)$, нормированный $\tfrac12(1, -1, 1, -1)$ (проверка: скалярные произведения с $b_1, b_2, b_3$ равны $0$).

**7. Размерность и базис.** Многочлены степени $\le n$: базис $1, x, \dots, x^n$, $\dim = n + 1$. Утверждение «множество многочленов степени $\le n$ с комплексными коэффициентами не является линейным пространством» **неверно**.

**8. Прикладная (из ФОС).** Пользователи $u = (3,1,5)$, $v = (1,2,4)$, $w = (5,0,6)$ (просмотры, лайки, минуты). Зависимость проверяют по определителю матрицы из них или поиском коэффициентов; если зависимы, один признак «восстанавливается» из других. Косинусное сходство: $\cos = \dfrac{(u,v)}{\lVert u\rVert\lVert v\rVert}$; $(u,v) = 3 + 2 + 20 = 25$, $(u,w) = 15 + 0 + 30 = 45$, $(v,w) = 5 + 0 + 24 = 29$; нормы $\lVert u\rVert = \sqrt{35}$, $\lVert v\rVert = \sqrt{21}$, $\lVert w\rVert = \sqrt{61}$; сходство $u,v$ равно $25/\sqrt{735}\approx0{,}922$, $u,w$ — $45/\sqrt{2135}\approx0{,}974$ (наибольшее), $v,w$ — $29/\sqrt{1281}\approx0{,}810$. Сумма двух векторов пространства — тоже вектор этого пространства (замкнутость), на этом основана генерация синтетических профилей.

## Типичные ошибки

- В матрице перехода записывают координаты по строкам вместо столбцов (или наоборот) и путают $T$ и $T^{-1}$.
- При ортогонализации забывают вычитать проекции на **все** предыдущие $b_i$.
- Считают, что любые $n+1$ векторов в $\mathbb{R}^n$ могут быть независимы (нет, зависимы всегда).
