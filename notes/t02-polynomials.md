## Главное

**Многочлен** от одной переменной над полем $P$ ($\mathbb{R}$ или $\mathbb{C}$): $f(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_1 x + a_0$, $a_n \ne 0$. Число $n = \deg f$ — **степень**, $a_n$ — старший коэффициент. Степень нулевого многочлена не определена.

Свойства степени: $\deg(f \pm g) \le \max(\deg f, \deg g)$, $\deg(fg) = \deg f + \deg g$ (для ненулевых).

## Деление и делимость

**Теорема о делении с остатком.** Для $f, g$ ($g \ne 0$) существует и единственна пара многочленов $q$ (частное) и $r$ (остаток), что

$$f = g\,q + r,\qquad r = 0 \text{ или } \deg r < \deg g.$$

Если $r = 0$, то $g$ **делит** $f$ ($g \mid f$). Свойства делимости: транзитивность; если $g \mid f_1$ и $g \mid f_2$, то $g \mid (f_1 u + f_2 v)$ для любых $u, v$; многочлены нулевой степени (числа) делят всё.

## НОД, НОК, алгоритм Евклида

**НОД** $(f, g)$ — многочлен наибольшей степени, который делит и $f$, и $g$ (определён с точностью до ненулевого множителя; обычно берут со старшим коэффициентом 1). Если $\mathrm{НОД} = 1$, многочлены **взаимно просты**.

**Алгоритм Евклида:** делим $f$ на $g$ с остатком, затем $g$ на остаток $r_1$, затем $r_1$ на $r_2$ и так далее, пока остаток не станет нулевым:

$$f = g q_1 + r_1,\quad g = r_1 q_2 + r_2,\quad r_1 = r_2 q_3 + r_3,\ \dots,\ r_{k-1} = r_k q_{k+1}.$$

Последний **ненулевой** остаток $r_k$ — это НОД. Остаток можно умножать на любое число, чтобы избавиться от дробей.

**Линейное выражение НОД:** из цепочки Евклида подстановкой снизу вверх получают $\mathrm{НОД}(f, g) = f u + g v$ для некоторых $u, v$.

**НОК:** $\mathrm{НОК}(f, g) = \dfrac{f g}{\mathrm{НОД}(f, g)}$ (с точностью до множителя).

## Корни, теорема Безу, схема Горнера

**Корень** многочлена — число $c$, при котором $f(c) = 0$.

**Теорема Безу.** Остаток от деления $f(x)$ на $(x - c)$ равен $f(c)$. Следствие: $c$ — корень $\iff (x - c) \mid f(x)$.

**Кратность корня** $c$ — наибольшее $k$, что $(x - c)^k \mid f(x)$. Корень кратности $k \ge 2$ является корнем производной $f'(x)$ кратности $k-1$.

**Схема Горнера** — быстрый способ делить на $x - c$ и вычислять $f(c)$. Для $f = a_n x^n + \dots + a_0$ строим $b_{n-1} = a_n$, $b_{k-1} = a_k + c\,b_k$; последнее число — остаток $= f(c)$, остальные — коэффициенты частного.

**Основная теорема алгебры.** Каждый многочлен степени $n \ge 1$ с комплексными коэффициентами имеет хотя бы один комплексный корень; с учётом кратности ровно $n$ корней.

Следствия для **действительных** коэффициентов: комплексные корни входят **парами сопряжённых**; неприводимые над $\mathbb{R}$ многочлены — линейные и квадратичные с $D < 0$. Любой многочлен раскладывается в произведение линейных и квадратичных множителей с $D < 0$.

**Рациональные корни.** Если несократимая дробь $p/q$ — корень многочлена с целыми коэффициентами, то $p \mid a_0$, $q \mid a_n$. Для старшего коэффициента 1 целые корни ищите среди делителей свободного члена.

## Разобранные примеры

**1. НОД алгоритмом Евклида.** $f = x^4 + 2x^3 - x^2 - 4x - 2$, $g = x^4 + x^3 - x^2 - 2x - 2$.

Делим $f$ на $g$: $f - g = x^3 - 2x$, частное $1$, остаток $r_1 = x^3 - 2x$.

Делим $g$ на $r_1$: $g = (x + 1)(x^3 - 2x) + (x^2 - 2)$, остаток $r_2 = x^2 - 2$.

Делим $r_1$ на $r_2$: $x^3 - 2x = x(x^2 - 2)$, остаток $0$.

Последний ненулевой остаток $x^2 - 2$, значит $\mathrm{НОД}(f, g) = x^2 - 2$. Проверка разложением: $f = (x+1)^2(x^2 - 2)$, $g = (x^2 - 2)(x^2 + x + 1)$.

**2. Взаимно простые.** $f = 2x^4 + 3x^3 - 3x^2 - 5x + 2$, $g = 2x^3 + x^2 - x - 1$.

$f = (x + 1)\,g + (-3x^2 - 3x + 3)$, берём $r_1 = x^2 + x - 1$ (разделили остаток на $-3$).

$g = (2x - 1)(x^2 + x - 1) + (2x - 2)$, берём $r_2 = x - 1$.

$x^2 + x - 1 = (x - 1)(x + 2) + 1$, остаток $1$. Значит $\mathrm{НОД} = 1$ (многочлены взаимно просты); $\mathrm{НОК} = fg$.

**3. Схема Горнера, значение.** $f(x) = x^4 + 2x^3 - 2x^2 - 2x + 2$ при $x = 2$. Коэффициенты $1,\ 2,\ -2,\ -2,\ 2$:

$1;\quad 2\cdot 1 + 2 = 4;\quad 2\cdot 4 - 2 = 6;\quad 2\cdot 6 - 2 = 10;\quad 2\cdot 10 + 2 = 22.$ Значит $f(2) = 22$.

**4. Корни и разложение.** $f(x) = x^4 - 5x^3 + 5x^2 + 5x - 6$. Кандидаты: делители числа $6$: $\pm1, \pm2, \pm3, \pm6$.

Проверяем $c = 1$: $1,\ -5,\ 5,\ 5,\ -6 \;\to\; 1,\ -4,\ 1,\ 6,\ 0$. Корень, частное $x^3 - 4x^2 + x + 6$.

Для него $c = -1$: $1,\ -4,\ 1,\ 6 \to 1,\ -5,\ 6,\ 0$. Корень, частное $x^2 - 5x + 6 = (x-2)(x-3)$.

Ответ: корни $1, -1, 2, 3$, $f = (x-1)(x+1)(x-2)(x-3)$.

**5. Кратность.** $f = (x-1)^2(x+2)$: корень $1$ кратности 2 (проверка: $f'(1) = 0$).

**6. Прикладная (из ФОС).** Время отклика $P(t) = t^2 - 8t + 15$. $P(3) = 9 - 24 + 15 = 0$, $P(5) = 25 - 40 + 15 = 0$; корни $3$ и $5$ (в 3 и 5 часов модель даёт нулевое время). Между корнями значения отрицательны ($P(4) = -1$), что физически невозможно: модель применима вне этого интервала, либо время ограничивают снизу нулём, либо берут другую модель.

## Типичные ошибки

- Забывают, что в Горнере пропущенные степени записываются нулевыми коэффициентами.
- Берут первый остаток вместо последнего ненулевого.
- При делении Евклида путают порядок: делят на предыдущий остаток, а не на частное.
- Для действительных коэффициентов теряют парность комплексных корней.
