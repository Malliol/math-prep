## Прямая на плоскости

Уравнения прямой:

- **Общее:** $Ax + By + C = 0$, нормальный вектор $\vec n = (A; B)$ перпендикулярен прямой.
- **С угловым коэффициентом:** $y = kx + b$, $k = \operatorname{tg}\alpha$ — тангенс угла наклона к оси $Ox$.
- **Через точку и направляющий вектор** $\vec s = (l; m)$ (каноническое): $\dfrac{x - x_0}{l} = \dfrac{y - y_0}{m}$; **параметрическое:** $x = x_0 + lt$, $y = y_0 + mt$.
- **Через две точки:** $\dfrac{x - x_1}{x_2 - x_1} = \dfrac{y - y_1}{y_2 - y_1}$.
- **В отрезках:** $\dfrac xa + \dfrac yb = 1$ (прямая отсекает отрезки $a$, $b$ на осях).
- **Через точку и нормаль:** $A(x - x_0) + B(y - y_0) = 0$.

**Взаимное расположение** прямых $y = k_1x + b_1$ и $y = k_2x + b_2$: параллельны $\iff k_1 = k_2$ (и $b_1 \ne b_2$); перпендикулярны $\iff k_1k_2 = -1$; угол между ними $\operatorname{tg}\varphi = \left\lvert\dfrac{k_2 - k_1}{1 + k_1k_2}\right\rvert$. Для общих уравнений: $\cos\varphi = \dfrac{\lvert\vec n_1\cdot\vec n_2\rvert}{\lvert\vec n_1\rvert\lvert\vec n_2\rvert}$.

**Расстояние от точки $M(x_0, y_0)$ до прямой $Ax + By + C = 0$:**

$$d = \frac{\lvert Ax_0 + By_0 + C\rvert}{\sqrt{A^2 + B^2}}.$$

## Плоскость в пространстве

- **Общее:** $Ax + By + Cz + D = 0$, нормальный вектор $\vec n = (A; B; C)$.
- **Через точку $M_0(x_0,y_0,z_0)$ и нормаль:** $A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$.
- **Через три точки** $M_1, M_2, M_3$ (не лежащие на одной прямой): смешанное произведение $(\overrightarrow{M_1M},\ \overrightarrow{M_1M_2},\ \overrightarrow{M_1M_3}) = 0$ (определитель $3\times3$) или нормаль $\vec n = \overrightarrow{M_1M_2}\times\overrightarrow{M_1M_3}$.
- **В отрезках:** $\dfrac xa + \dfrac yb + \dfrac zc = 1$.

**Угол между плоскостями** — угол между нормалями: $\cos\varphi = \dfrac{\lvert\vec n_1\cdot\vec n_2\rvert}{\lvert\vec n_1\rvert\lvert\vec n_2\rvert}$. Параллельны $\iff\vec n_1\parallel\vec n_2$; перпендикулярны $\iff\vec n_1\cdot\vec n_2 = 0$.

**Расстояние от точки до плоскости:**

$$d = \frac{\lvert Ax_0 + By_0 + Cz_0 + D\rvert}{\sqrt{A^2 + B^2 + C^2}}.$$

**Пучок плоскостей**, проходящих через прямую $\alpha_1 = 0$, $\alpha_2 = 0$: $\lambda\alpha_1 + \mu\alpha_2 = 0$. Аналогично пучок прямых на плоскости.

## Прямая в пространстве

- **Каноническое:** $\dfrac{x - x_0}{l} = \dfrac{y - y_0}{m} = \dfrac{z - z_0}{n}$, $\vec s = (l; m; n)$ — направляющий вектор.
- **Параметрическое:** $x = x_0 + lt$, $y = y_0 + mt$, $z = z_0 + nt$.
- **Через две точки:** направляющий вектор $\overrightarrow{M_1M_2}$.
- **Общее (как пересечение двух плоскостей):** $\begin{cases} A_1x + B_1y + C_1z + D_1 = 0 \\ A_2x + B_2y + C_2z + D_2 = 0 \end{cases}$, направляющий вектор $\vec s = \vec n_1\times\vec n_2$; точку находят, придав одной переменной значение (например, $z = 0$).

**Прямая и плоскость.** Угол $\varphi$ между прямой и плоскостью: $\sin\varphi = \dfrac{\lvert\vec s\cdot\vec n\rvert}{\lvert\vec s\rvert\lvert\vec n\rvert}$. Подстановка параметрических уравнений прямой в уравнение плоскости даёт уравнение на $t$: одно решение — прямая пересекает плоскость; нет решения — параллельна; любое $t$ — лежит в плоскости. Условие параллельности: $\vec s\cdot\vec n = 0$.

**Две прямые в пространстве** с направляющими $\vec s_1, \vec s_2$ и точками $M_1, M_2$: параллельны, если $\vec s_1\parallel\vec s_2$; пересекаются, если не параллельны и $(\vec s_1, \vec s_2, \overrightarrow{M_1M_2}) = 0$; **скрещиваются**, если $(\vec s_1, \vec s_2, \overrightarrow{M_1M_2}) \ne 0$. Угол между прямыми — между направляющими; перпендикулярны при $\vec s_1\cdot\vec s_2 = 0$. Расстояние между скрещивающимися прямыми: $d = \dfrac{\lvert(\vec s_1, \vec s_2, \overrightarrow{M_1M_2})\rvert}{\lvert\vec s_1\times\vec s_2\rvert}$ (длина общего перпендикуляра).

## Разобранные примеры

**1. Прямая через две точки.** $A(2, -1)$, $B(-4, 5)$: направляющий $\overrightarrow{AB} = (-6, 6)\sim(-1, 1)$. Уравнение $\dfrac{x - 2}{-1} = \dfrac{y + 1}{1}$, т. е. $x + y - 1 = 0$. Точка $C(1, 0)$: $1 + 0 - 1 = 0$ — лежит на прямой. Точка $C(2, 0)$: $2 - 1 = 1 \ne 0$ — не лежит.

**2. Расстояние точка–прямая.** $M(3, -2)$, прямая $4x - 3y + 6 = 0$: $d = \dfrac{\lvert12 + 6 + 6\rvert}{\sqrt{16 + 9}} = \dfrac{24}{5} = 4{,}8$.

**3. Угол между прямыми.** $y = 2x + 3$ и $y = -\tfrac12x + 1$: $k_1k_2 = 2\cdot(-\tfrac12) = -1$, прямые перпендикулярны.

**4. Плоскость через три точки.** $M_1(1, 0, 2)$, $M_2(0, 1, 1)$, $M_3(2, 1, 1)$: $\overrightarrow{M_1M_2} = (-1, 1, -1)$, $\overrightarrow{M_1M_3} = (1, 1, -1)$, нормаль $\vec n = \overrightarrow{M_1M_2}\times\overrightarrow{M_1M_3} = (0;\ -2;\ -2)\sim(0, 1, 1)$. Уравнение $y + (z - 2) = 0$, т. е. $y + z - 2 = 0$. Проверка: $M_2$: $1 + 1 - 2 = 0$; $M_3$: $1 + 1 - 2 = 0$; $M_1$: $0 + 2 - 2 = 0$.

*Предостережение.* Точки $A(1,0,2)$, $B(0,-1,3)$, $C(2,1,1)$ из ФОС лежат на одной прямой ($\overrightarrow{AB} = (-1,-1,1)$, $\overrightarrow{AC} = (1,1,-1) = -\overrightarrow{AB}$), через них проходит бесконечно много плоскостей. Всегда проверяйте, не коллинеарны ли векторы, прежде чем искать нормаль.

**5. Плоскость по точке и нормали.** $K(1, -1, 2)$, $\vec n = (2, -3, 5)$: $2(x - 1) - 3(y + 1) + 5(z - 2) = 0 \Rightarrow 2x - 3y + 5z - 15 = 0$.

**6. Расстояние точка–плоскость.** $P(2, -3, 1)$, $3x - 4y + 12z - 5 = 0$: $d = \dfrac{\lvert6 + 12 + 12 - 5\rvert}{\sqrt{9 + 16 + 144}} = \dfrac{25}{13}$.

**7. Пересечение прямой и плоскости.** Прямая $x = 1 + 2t$, $y = -1 + t$, $z = 3 - t$, плоскость $2x + y - z + 4 = 0$. Подстановка: $2 + 4t - 1 + t - 3 + t + 4 = 6t + 2 = 0$, $t = -\tfrac13$. Точка $\left(\tfrac13;\ -\tfrac43;\ \tfrac{10}{3}\right)$.

**8. Угол между плоскостями.** $2x + y - z = 4$ и $x - y + 3z = 7$: $\vec n_1 = (2, 1, -1)$, $\vec n_2 = (1, -1, 3)$, $\vec n_1\cdot\vec n_2 = 2 - 1 - 3 = -2$, $\lvert\vec n_1\rvert = \sqrt6$, $\lvert\vec n_2\rvert = \sqrt{11}$, $\cos\varphi = \dfrac{2}{\sqrt{66}}\approx0{,}246$, $\varphi\approx75{,}7^\circ$ (берём модуль, острый угол).

**9. Прикладная (из ФОС).** Луч через $A(1,0,2)$ и $B(4,3,8)$: направляющий $\overrightarrow{AB} = (3,3,6)\sim(1,1,2)$; параметрически $x = 1 + t$, $y = t$, $z = 2 + 2t$ (или с $(3,3,6)$).

## Типичные ошибки

- В формуле расстояния забывают модуль в числителе или корень в знаменателе.
- В угле между плоскостями или прямыми не берут модуль скалярного произведения (угол между прямыми острый).
- Путают направляющий вектор прямой и нормаль плоскости; для угла прямая–плоскость в числителе стоит $\sin\varphi$, а не $\cos\varphi$.
